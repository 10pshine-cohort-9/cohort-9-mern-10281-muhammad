# Notpad

A simple MERN notes application built for the 10Pearls Shine — Cohort 9 assignment.

## Stack

* React + TypeScript
* Node.js + Express
* MongoDB
* Tailwind CSS
* pnpm + Turborepo

## Setup

```bash
pnpm install
pnpm dev
```

Create the required environment variables for the API before running the project.

## Structure

```text
apps/
├── web/   # Frontend
└── api/   # Backend
```
